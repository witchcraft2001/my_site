`GIFVIEW.EXE` показывает статические и анимированные GIF-файлы на экране Sprinter 320×256. Программа декодирует изображения LZW, поддерживает чересстрочную развёртку, прозрачность, локальные палитры и способы замещения кадров анимации.

## Возможности

- воспроизведение GIF-анимации с задержками, записанными в файле;
- однократное воспроизведение и остановка после последнего кадра;
- вывод сведений о GIF без перехода в графический режим;
- показ изображения без масштабирования по центру экрана;
- ускоренный режим без межкадровых задержек для оценки скорости декодера.

## Запуск

```text
GIFVIEW.EXE [options] <filename.gif> [options]
```

Ключи: `-center` — центрировать изображение без масштабирования, `-i` — вывести информацию, `-once` — проиграть один раз, `-fast` — игнорировать задержки кадров.
